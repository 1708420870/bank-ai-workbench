# 客户反馈小程序（第二期 M4）

原生微信小程序，对接反馈网关（outer 8103）。方案说明见《07-客户反馈小程序方案》，
分发约束见《25-分发与迁移指南》第十节。

## 一句话结论

小程序**不能像桌面 exe 那样打包搬走**。它的「迁移」是三件事：代码目录 + AppID + 一个
手机能访问到的 HTTPS 域名。给同事自测走「开发版」，给客户看走「体验版/正式版」，两者
前置条件不同——见下表。

| 使用方式 | 对方需要什么 | 是否需要公网域名 | 适合场景 |
|---|---|---|---|
| 开发版（微信开发者工具） | 装开发者工具 + 被加为项目成员 | 否，勾选「不校验合法域名」即可 | 同事自测、改代码 |
| 体验版（手机微信扫码） | 装微信 + 被加为体验成员 | **是**，request 必须 HTTPS 且已备案并配白名单 | 给客户/领导真机看效果 |
| 正式版 | 微信用户 | **是**，同上 + 提审通过 | 上线 |

体验版同样是线上环境，域名校验与正式版一致；只有开发者工具和「开发调试」模式能临时跳过。

## 打开方式（开发版）

1. 安装并打开**微信开发者工具**
2. 「导入项目」→ 目录选择本目录（`miniprogram/`）
3. AppID 填 `project.config.json` 里那个，或换成你自己的（无 AppID 可选「测试号」）
4. 「详情 → 本地设置」勾选 **不校验合法域名**（开发阶段必须）

## 服务地址（改一个文件即可）

地址集中在 `config.js`，`app.js` 启动时读取：

```js
const ENV = 'lan'          // localhost | lan | public
const PRESETS = {
  localhost: 'http://127.0.0.1:8103',
  lan:       'http://10.99.224.207:8103',   // ← 换成运行包那台电脑的局域网 IP
  public:    'https://feedback.example.com' // ← 体验版/正式版：备案 HTTPS 域名
}
```

- 同事拿到项目后，**只改 `config.js` 里 `lan` 那一行**（IP 由「启动-局域网.bat」启动时打印）
- 手机与电脑必须同一 Wi-Fi；电脑防火墙首次会弹提示，选「允许访问」
- 现场临时换地址不想改代码，可在开发者工具 Console 执行：

```js
wx.setStorageSync('gateway_override', 'http://192.168.1.5:8103')
```

清掉用 `wx.removeStorageSync('gateway_override')`。启动时会打印实际生效的地址。

## 真机没有域名怎么办

两条可行路径，按成本从低到高：

1. **先用 H5 顶替**（推荐给现场演示）。后端包里的外区 8103 自带 H5 页面，内容与小程序
   一致，手机浏览器直接开 `http://<电脑IP>:8103/` 即可，零 AppID、零备案、零白名单。
2. **走 HTTPS 域名**。用单位已有备案域名加一条子域反向代理到 8103，再在
   mp.weixin.qq.com「开发管理-开发设置-服务器域名」把该域配进 request 合法域名。
   个人演示也可用内网穿透拿到临时 HTTPS 域名，但**不能用于对外交付**。

## 客户身份说明

PoC 用本地生成的稳定伪 openid（`fb_openid`）标识客户。生产应替换为
`wx.login` → code2session 换取的真实 openid（换取由行方后端完成，前端不接触密钥）。

## 页面

| 页面 | 功能 |
|------|------|
| pages/index | 提单（业务类型 + 描述，500 字上限，敏感信息提示） |
| pages/tickets | 我的反馈列表 + 按单号查询 |
| pages/chat | 会话详情：AI/人工消息、追加消息（未办结）、办结后评价 |

消息 5 秒轮询刷新；评价走 `kind=eval` 经 DMZ 入站链路落内网（仅统计，不进会话）。
