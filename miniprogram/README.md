# 客户反馈小程序（第二期 M4）

原生微信小程序，对接反馈网关（outer 8103）。接入说明见《07-客户反馈小程序方案》。

## 打开方式

1. 安装并打开**微信开发者工具**
2. 「导入项目」→ 目录选择本目录（`miniprogram/`）
3. AppID 填你在 mp.weixin.qq.com 注册拿到的小程序 AppID（或先用"测试号"）
4. 「详情 → 本地设置」勾选 **不校验合法域名**（PoC 阶段必须，正式发布需 HTTPS + 备案 + 域名白名单）

## 服务地址

`app.js` 里 `globalData.gateway` 默认 `http://127.0.0.1:8103`（开发者工具本机演示）。
真机预览时改成开发机的**局域网 IP**（如 `http://192.168.x.x:8103`），并保证手机与开发机同网段、三区服务已启动。

## 客户身份说明

PoC 用本地生成的稳定伪 openid（`fb_openid`）标识客户。生产应替换为
`wx.login` → code2session 换取的真实 openid（换取由行方后端完成，前端不接触密钥）。

## 页面

| 页面 | 功能 |
|------|------|
| pages/index | 提单（业务类型 + 描述，500 字上限，敏感信息提示） |
| pages/tickets | 我的反馈列表 + 按单号查询 |
| pages/chat | 会话详情：AI/人工消息、追加消息（未办结）、办结后评价 |

消息 5 秒轮询刷新；评价走 `kind=eval` 经 DMZ 入站链路落内网（仅统计，不进会话）。
