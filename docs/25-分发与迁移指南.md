# 分发与迁移指南（给同事拿去测试用）

版本：v1.5.0　更新：2026-11-18

## 一、为什么需要打包

线上演示链接有两个绕不开的约束：一是必须带 `?sharecode=` 整段参数，转发时极易被
聊天工具截断（截断后平台返回 403「链接不完整」）；二是线上沙箱属平台托管，随时可能
被回收或限流。要让同事「拿走就能测」，必须给一份**不依赖原作者电脑、也不依赖公网**
的可执行分发包。

## 二、三种分发形态对比

| 形态 | 同事侧前置条件 | 体积 | 隔离保真度 | 适用场景 |
|---|---|---|---|---|
| **A. 绿色包（本次交付）** | 无，解压双击 | 37.7 MB | 线程级 + 独立库 | 拿去测试、走访演示、离线环境 |
| B. Docker Compose | 装 Docker Desktop | 镜像约 300 MB | 三网络拓扑，最高 | 技术评审、贴近生产的部署验证 |
| C. 源码 + venv | 装 Python 3.11+ 并联网装依赖 | 约 150 MB | 进程级 | 需要改代码的人 |
| D. 线上链接 | 浏览器 | — | 单进程多路由 | 快速围观，不适合正式测试 |

**结论**：给同事测试选 A；要做架构评审选 B；两者可以并行给，不冲突。

## 三、绿色包里有什么

```
银行客服AI工作台-v1.5.0-win64/
├─ 启动.bat              ← 双击这个
├─ 启动-局域网.bat        ← 手机要访问时用这个
├─ 重置演示数据.bat        ← 恢复出厂演示数据
├─ 使用说明.txt           ← 给同事看的一页纸
├─ BankAIWorkbench.exe   ← 主程序（12 MB）
└─ _internal/            ← 内嵌 Python 运行时 + 全部依赖 + 前端页面（约 190 MB）
```

解压后 841 个文件。首次启动时在包内自动创建 `data/`（三个库 + 日志）：

| 文件 | 作用 | 首次启动后大小 |
|---|---|---|
| `data/inner.db` | 内网：客户、交易、案例、规则、工单、审计（19 张表） | 184 KB |
| `data/dmz.db` | DMZ：脱敏令牌映射、裁决记录 | 16 KB |
| `data/outer.db` | 外网：反馈工单、回复 | 44 KB |

种子数据自动写入：6 个客户、6 个账号、12 个合成案例，无需手动初始化。

## 四、同事侧操作（三步）

1. 解压到本地磁盘（**不要**在压缩包里直接双击，也不要放在只读目录或网盘映射盘）
2. 双击 `启动.bat`，等 5–10 秒，浏览器自动打开登录页
3. 登录 `b001 / abc122333`（坐席）或 `a001 / abc123456`（管理端 `/admin`）

黑色控制台窗口不要关，关掉即停止服务。程序启动时会自行检测：若发现已在运行，
直接打开浏览器而不是报「端口被占用」。

## 五、迁移与备份

- **迁移**：整个文件夹（含 `data/`）拷走即完成迁移，换电脑、换盘符都不影响。
- **备份**：停掉程序后复制 `data/` 目录即可；热备需同时复制 `-wal` / `-shm` 文件。
- **重置**：双击 `重置演示数据.bat`（会二次确认），或关闭程序后删除 `data/`。
- **不迁移**：`_internal/` 与源码版本绑定，升级版本时整包替换，不要只替换 exe。

## 六、常见故障

| 现象 | 原因 | 处置 |
|---|---|---|
| 双击 exe 一闪而过 | 直接被拦截或崩溃 | 用 `启动.bat` 启动，窗口会保留报错 |
| 提示端口被占用 | 8101–8103 被别的程序占 | 关掉占用程序；或改 `INNER_PORT/DMZ_PORT/OUTER_PORT` 为 18101/18102/18103 |
| 杀软报毒/拦截 | PyInstaller 引导器误报（常见） | 加入信任后重试 |
| 浏览器空白 | 端口写错或浏览器缓存 | 确认地址是 `127.0.0.1:8101/login`，换 Chrome/Edge |
| 手机打不开 | 只跑了 `启动.bat`（仅监听回环） | 改用 `启动-局域网.bat`，并在防火墙提示里选「允许」 |
| 模型回答退化为模板 | 连不上牛马仕 GPU 端点（`106.55.2.189:8000`） | 属设计内降级，业务链路不受影响；需要真实推理时确认对方网络可达 |

## 七、重新构建

```bash
pip install pyinstaller
python build_desktop.py
```

脚本做三件事：PyInstaller 打包（`dist/<时间戳>/`）→ 组装发行目录并写入三个 bat 与
说明文件（`release/`）→ 压成 zip。版本号取自 `common/config.py` 的 `APP_VERSION`，
发包前改版本号即可。

两处工程约束（都已在脚本里处理，改动时勿回退）：

1. **每次构建落到独立的时间戳目录**。PyInstaller 的 `--noconfirm` 会整目录删除旧产物，
   文件数上千时可能被系统的批量删除保护拦下，表现为 COLLECT 阶段失败。
2. **压缩包名不能用 `Path.with_suffix(".zip")`**。目录名含 `v1.5.0-win64`，
   `with_suffix` 会把 `.0-win64` 当扩展名替换，生成 `…-v1.5.zip` 这类错名。
3. **批处理必须是纯 ASCII**。cmd.exe 按当前代码页逐字节解析 `.bat`，UTF-8 中文行会被
   按字节边界截断，实测报 `'xxx' is not recognized as an internal or external command`
   并中断后续命令；改成 GBK 又依赖系统区域设置，且 GBK 尾字节可能落在 `|` `&` 等元字符上。
   因此三个 bat 只保留 ASCII，**所有中文提示由 exe 自己打印**（Python 走宽字符控制台
   API，与代码页无关）。局域网地址探测也从 bat 的 `ipconfig` 解析搬进了程序。

## 八、与冻结模式相关的两处代码适配

| 位置 | 问题 | 处理 |
|---|---|---|
| `common/config.py` | 冻结后 `__file__` 落在 `_internal/` | 已用 `sys.frozen` 分流：只读资源取 `_MEIPASS`，可写数据取 exe 同级 |
| `outer/app.py` | H5 目录用 `Path(__file__).parent.parent/"h5"`，冻结后路径不存在 → 客户反馈页 500 | 已改为基于 `config.ROOT` |

## 十、边界与限制

1. **仅 Windows x64**。PyInstaller 产物不能跨平台，同事用 macOS/Linux 需在其本机重新构建。
2. **PoC 演示件，不是生产系统**。口令、`SESSION_SECRET`、`DATA_KEY` 均为演示级常量，
   真实投产须替换为行内 SSO、KMS/HSM 与堡垒机审计。
3. **线程级隔离只用于演示**。三区在同一个进程内以线程运行、各自独立 SQLite；真实边界
   形态是 `docker-compose.yml` 的三网络拓扑。
4. **内网算力依赖外部可达性**。真实推理走 `HERMES_BASE_URL`，不可达时自动降级为确定性
   Mock，界面会出现「已降级」类提示，业务链路仍可完整演示。
