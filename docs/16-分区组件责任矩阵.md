# 分区组件责任矩阵

> 对应审计编号：**R4 / M2 / A2 / B6**
> 判定口径：每个组件写明「持有数据 / **不持有**数据 / 暴露接口 / 审批主体」。**外网列凡涉及原始数据、令牌映射、规则全文，一律填「无」。**

---

## 1. 总表

| 组件 | 所属域 | 持有数据 | **明确不持有** | 暴露接口 | 审批主体 |
|---|---|---|---|---|---|
| **employee/customer 库**（`inner.db: customers, employees, transactions`） | 内网 | 客户姓名、证件号、卡号、手机号、账户余额、交易流水；员工工号/姓名/角色 | — | 仅内网服务层函数调用，**不对外暴露 HTTP** | 数据合规 + 内网运维 |
| **规则库**（`inner.db: rules`） | 内网 | 规则全文、适用条件、版本、出处、生效日期 | — | `get_rule_metadata` / `get_approved_rule_summary`（**仅摘要**经 MCP） | 业务规则委员会 |
| **令牌映射表**（`inner.db: token_map`，`sealed_value` AES 加密） | 内网 | token → 真实值（加密存储） | — | **无任何对外接口**；仅 `restore_for_display` 内部调用 | 安全 + 数据合规 |
| **脱敏服务**（`inner/privacy.py`） | 内网 | 运行期内存中的姓名库 | 不持有映射表明文 | 进程内函数 | 安全 |
| **牛马仕 Agent**（`inner/agent.py`） | 内网 | 任务上下文（已脱敏）、规划步骤、结构化建议 | **不持有**客户库、映射表、生产写权限 | 进程内；对外仅经工作台 API | 科技 + 安全 |
| **内网工作台 API**（`inner/app.py`） | 内网 | 工单、审计事件、会话 | 不持有外网任务元数据 | `:8101/internal/api/v1/*`（需登录会话） | 科技 |
| **审计库**（`inner.db: events`、`dmz.db: events`） | 内网 + DMZ | 事件、request_id、trace_id、规则/模型版本、工具调用 | **不记录客户原文/PII** | 导出接口（审核员权限） | 安全 + 内审 |
| **DMZ 交换网关**（`dmz/app.py`） | DMZ | 内存态 `_SEEN` 重放窗口（request_id + 时间戳，TTL 600s）、审计事件 | **不持有**客户原文、令牌映射、完整业务库；**无客户表** | `:8102/dmz/api/v1/dispatch`、`/mcp/call` | 网络 + 安全 |
| **MCP 受控网关**（DMZ `/mcp/call`） | DMZ | 工具名、参数键名（**不记参数值**）、角色 | 不持有任何业务数据 | 同上（需服务令牌） | 安全 + 科技 |
| **外网 AI 协同服务**（`outer/app.py`） | 外网 | 任务元数据（脱敏上下文、意图、请求号）、模拟应答 | **不持有**：客户原始数据 / token 映射 / 完整客户档案 / 规则全文 / 内网地址 | `:8103/outer/api/v1/tasks` | 科技（外网侧） |
| **WorkBuddy 企业版/Managed Agents** | 外网 | 会话、任务队列、提示词模板（仅脱敏内容） | **不持有**同上五项 | 平台 API（**待租户核实**，见 `docs/12`） | 甲方 IT + 商务 |
| **外部大模型服务** | 外网 | 单次请求的最小上下文（脱敏） | **不持有**任何持久化客户数据（依赖数据处理条款 V5） | 供应商 API | 商务 + 合规 |
| **科技开发入口**（WorkBuddy Skill/Workflow） | 外网 | 草稿代码、合成样例 | **不持有**真实客户数据（强制约束） | 经 MCP Connector → DMZ | 科技 |

## 2. 数据出域矩阵（谁的数据能到哪）

| 数据类别 | 内网 | DMZ | 外网 | 依据 |
|---|---|---|---|---|
| 客户姓名明文 | ✅ | ❌ | ❌ | `privacy.mask` 令牌化 |
| 证件号 / 卡号 / 手机号 | ✅ | ❌ | ❌ | 确定性正则 + 自检残留阻断 |
| 金额 / 完整交易流水 | ✅ | ❌ | ❌ | 金额脱敏规则；白名单无该字段 |
| 令牌映射表 | ✅（加密） | ❌ | ❌ | 无接口、不入库 DMZ |
| 规则全文 | ✅ | ❌ | ❌ | 只出 id/version/summary |
| 规则摘要 | ✅ | ✅ | ✅ | `approved_rule_context` |
| 意图类别码 | ✅ | ✅ | ✅ | `intent_hint` |
| 令牌化文本（`NAME_001`…） | ✅ | ✅ | ✅ | `sanitized_context` |
| 审计事件 | ✅ | ✅ | ❌ | DMZ 审计留 DMZ，不回传外网 |
| 员工身份（工号/角色） | ✅ | ✅（仅角色+actor 用于 MCP 授权） | ❌ | MCP 调用带 role/actor，不外发 |

> **注**：MCP 调用中 `actor`（工号）会经 DMZ 传到内网 Facade，属"回程"方向，不出外网。外网侧无任何员工标识。

## 3. 接口暴露面清单（对外可达 = 有网络端口 + 有路由）

| 区 | 端口 | 路径 | 鉴权 | 可达来源 |
|---|---|---|---|---|
| inner | 8101 | `/login`、`/client`、`/admin`（页面） | 会话 Cookie | 员工浏览器 |
| inner | 8101 | `/internal/api/v1/*` | 会话 Cookie 或服务令牌 | 员工浏览器 / DMZ 服务令牌 |
| dmz | 8102 | `/dmz/api/v1/dispatch` | HMAC 签名（`SECRET_INNER_DMZ`） | 仅 inner |
| dmz | 8102 | `/dmz/api/v1/mcp/call` | 服务令牌 + 角色 | 仅 inner |
| dmz | 8102 | `/dmz/api/v1/health` | 无 | 监控 |
| outer | 8103 | `/outer/api/v1/tasks` | HMAC 签名（`SECRET_DMZ_OUTER`） | **仅 dmz** |
| outer | 8103 | `/outer/api/v1/health` | 无 | 监控 |

**outer 区配置层不含 `INNER_URL` / `INNER_PORT`**（`common/config.py`），即"直连内网"在代码里无址可依，不是靠约定禁止。

## 4. 审批主体与变更权限（RACI 简表）

| 变更类型 | R（执行） | A（批准） | C（咨询） | I（知会） |
|---|---|---|---|---|
| 出域字段白名单增删 | 科技 | **安全** | 数据合规 | 网络 |

| 模型端点登记/变更 | 科技 | **科技 + 安全** | 业务 | 合规 |

| 审计留存期调整 | 安全 | 安全 | 内审 | 科技 |
| Skill/Workflow 发布 | 科技 | **主管 + 安全** | 业务 | 内审 |
