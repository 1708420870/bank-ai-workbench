## 一、演示动线（建议 8-10 分钟）

> 两条设备线：**演示笔记本**（坐席+管理端）+ **手机**（客户身份，用热点或现场 WiFi）。
> 演示前把两台设备都调好：笔记本浏览器开三个标签页备用（坐席工作台 / 管理控制台 / 登录页）。
>
> 💡 11-17 按导师意见优化后的 AI 卖点：AI 答复为自然客户话术（意图/风险等内部分析只进审计，
> 可在管理端审计日志展示内部口径）；资金安全类问题 AI 先安抚再转人工；多轮对话不重复追问；
> 被问费率等无依据问题时 AI 主动说明「以银行最新公告为准」——可现场演示这些点。

### 第 1 幕：模拟客户发问 + 现场观看 AI 实时应答（约 2-3 分钟）
1. 手机打开演示页（`set LAN_BIND=1 && python run_local.py` 启动后控制台打印的地址）
2. 选「贷款」→ 输入"我想咨询提前还贷的流程" → 提交
3. **卖点话术**：客户消息经外网网关 → DMZ 脱敏裁决 → 内网 AI 生成答复，全程毫秒级
4. 指着坐席端会话展示：客户身份证号/卡号已被脱敏成 `********`
5. 手机追问一句"最长可以贷几年" → 展示 AI **带上下文的多轮应答**（这是"现场观看大模型回复"的核心亮点）

### 第 2 幕：人工回复与客户互聊（约 3 分钟）
1. 手机发"转人工" → 状态变「待人工接管」
2. 笔记本坐席端（b001）红点亮起 → 点「客户反馈」→ 接管 → 回复
3. **互聊演示**：手机再追问"那违约金怎么算" → 坐席回复 → 客户再评价——来回 2-3 轮，展示真人对话流
4. **卖点话术**：回复要过 DMZ 口径红线裁决——当场演示一条违规回复被拦截（输入"保本保息稳赚不赔"→ 系统拒绝下发）——这是全链路风控的最大亮点
5. 另开一个浏览器窗口登录 b002，展示**多坐席红点同步**：b001 接管后 b002 红点同步消失；b002 再点接管被拒（409 已由他人接管）

### 第 3 幕：办结闭环 + 查阅档案（约 2-3 分钟）
1. 手机评价（👍）→ 工单办结
2. 坐席端「我的档案」→ 展示本人经手的每一单历史
3. 切到管理控制台（a001）→「工作档案」→ 展示按坐席汇总的处理记录（接管 N 单、办结 N 单）
4. **卖点话术**：每一单都有全链路审计记录，AI 只建议、不裁决，数据不出内网

### 第 4 幕（可选）：私信 + OA（约 1 分钟）
- 坐席之间互发私信、看 OA 通知——展示这是完整的行内工作台，不只是反馈工单

## 五、演示亮点一句话清单（被问随时甩）

1. **三区隔离架构**：外网网关 / DMZ 裁决区 / 内网核心，公网面只有反馈 API 一个入口
2. **双重脱敏**：DMZ 形态脱敏（卡号/证件/手机号）+ 内网姓名级二次脱敏
3. **AI 只建议不裁决**：AI 答复与坐席回复都要过 DMZ 规则裁决，fail-closed
4. **口径红线**：保本/稳赚/全额退款等承诺类表述确定性拦截
5. **多轮 AI 会话**：客户说"转人工"才切换人工，全程有上下文
6. **多坐席协同**：红点全员同步、接管互斥、工作档案全记录
7. **AI 降级兜底**：算力不可达自动切本地模板应答，业务永不中断
