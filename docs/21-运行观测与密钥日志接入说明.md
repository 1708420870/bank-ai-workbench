## 2. 观测指标口径（防"数字好看但没意义"）

`/internal/api/v1/observe` 返回：

| 指标 | 计算式 | 为什么这么算 |
|---|---|---|
| `tickets.fail_rate` | `REJECTED + TIMEOUT + BLOCKED` / 全部工单 | 这三态就是"AI 建议没能进工作台"，是真正的交付失败 |
| `rules.hit_rate` | `rule_ids` 非空的工单 / 全部 | 规则没命中说明规则库覆盖不足，而不是"AI 更聪明" |
| `human.handoff_rate` | `decision=HUMAN_HANDOFF` / 已裁决工单 | 转人工率异常升高 = 模型质量或网关在退化 |
| `mcp.denied` | `MCP_DENIED` 事件数（inner+dmz） | 越权尝试的直接计数 |
| `mcp.rate_limited` | `RATE_LIMITED` 事件数 | 限流是否真的在起作用（为 0 要么没攻击、要么限流没生效） |
| `egress.deny_rate` | `EGRESS_DENIED / (ACCEPTED + DENIED)` | DLP 拦截强度 |
| `restore_denied` | `RESTORE_DENIED` 事件数 | 越权回填尝试 |
| `endpoints` | 工单按 `model_supplier` 分组 | 实际用了哪些端点（而不是"配置里有哪些"） |

**窗口说明**：审计事件按"近 500 条"取，工单按全量。窗口写进返回体 `window` 字段，避免读数的人误以为是全时段。

## 3. trace_id 贯穿设计（R11 关闭证据）

```
浏览器请求 ──X-Trace-Id(无)→ inner 中间件生成 TR-xxxxxxxx
                              │  audit.set_trace(tid)  ← 本请求所有审计事件自动继承
                              ├─→ 调 DMZ：headers={"x-trace-id": tid}
                              │        └─ DMZ 中间件 set_trace → 其审计同一 trace
                              └─→ 回写响应头 X-Trace-Id（便于用户侧排查）
```

- 有 `request_id` 的事件：`trace_id = request_id`（业务链路天然同源）
- 无 `request_id` 的事件（登录失败、健康检查、限流）：`trace_id = 中间件生成的 TR-*`
- **结果**：审计里不再出现 `trace_id` 为空的行。

复验：
```bash
python tools/audit_export.py --data-dir data_test
# 输出 by_event 后，检查 json 中 trace_id 空值数量
python -c "
import json,glob
f=sorted(glob.glob('evidence/audit/audit-export-all-*.json'))[-1]
d=json.load(open(f,encoding='utf-8'))
empty=[e for e in d['events'] if not e.get('trace_id')]
print('trace_id 为空的事件数:', len(empty), '/', len(d['events']))"
```

## 4. 生产适配层接口（给甲方安全/运维的接入点）

> 目标：把 PoC 的"软件密钥 + 本地日志"替换为行内基础设施，**业务代码不改**，只换适配器。

### 4.1 密钥服务（KMS/HSM）

```python
# common/kms.py（待实现，PoC 用 env 变量替代）
class KeyProvider(Protocol):
    def get(self, key_id: str) -> bytes: ...          # 取数据密钥（可缓存，带 TTL）
    def rotate(self, key_id: str) -> bytes: ...       # 轮转：返回新密钥，旧密钥保留解密能力
    def sign(self, key_id: str, payload: bytes) -> str: ...
```

| 需替换的常量 | 现状 | 生产要求 |
|---|---|---|
| `SECRET_INNER_DMZ` / `SECRET_DMZ_OUTER` | 环境变量明文（PoC） | KMS 托管，90 天轮转，双密钥并行期 |
| `DATA_KEY`（令牌映射加密） | 环境变量明文（PoC） | HSM 内加密/解密，密钥不出硬件 |
| `SESSION_SECRET` | 环境变量明文（PoC） | KMS 托管 |

**接入判据**：能在不重启服务的前提下轮转密钥，且旧会话/旧令牌仍可解密（密钥版本化）。

### 4.2 日志平台

```python
# common/logger.py 现状：JSON Lines 落本地文件
```

字段要求（缺一不可）：`ts`、`zone`、`event`、`request_id`、`trace_id`、`actor`、`severity`、`data`。
