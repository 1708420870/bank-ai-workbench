# 接口说明（API Reference）

> 生成日期：2026-11-17 · 由 FastAPI OpenAPI schema 自动导出（inner 50 + outer 11 + dmz 7 = 68 个端点）
> 各区运行中可访问 `/docs` 查看交互式文档（仅内网/回环可达）。

## 鉴权口径

| 区域 | 鉴权方式 |
|---|---|
| 内网区（inner，端口 8101） | Cookie `wb_sid`（登录签发）或 `Authorization: Bearer <token>`；服务间调用用 `x-service-token` 头 |
| 外网区（outer，端口 8103） | 客户身份为 `openid` 参数/体字段（PoC 阶段由客户端本地生成，生产应换微信 code2session） |
| 脱敏代理区（dmz，端口 8102，仅回环） | 服务令牌 `x-service-token`（inner→dmz ingest 专用），不对外暴露 |

> 口令类字段（工号/密码/口令）一律不写入本文档；种子账号见桌面点对点发放，演示数据由 `reset_demo_data.py` 重建。

## 建议链路速查

- **坐席处理客户反馈**：`POST /internal/api/v1/feedback/list` → `POST /feedback/{{id}}/takeover`（409 冲突保护）→ `POST /feedback/{{id}}/reply` → `POST /feedback/{{id}}/close`
- **客户提单**：`POST /feedback/api/v1/tickets`（outer）→ AI 应答（经 DMZ 裁决）→ 多轮 `POST /feedback/api/v1/tickets/{{id}}/messages` → 评价
- **数据出域**：内网取数 → 确定性脱敏（映射表只在内网）→ `POST /dmz/api/v1/ingest`（x-service-token）→ 规则裁决 → 结果回流
