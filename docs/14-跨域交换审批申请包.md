## 2. 数据流与字段白名单（审批核心）

### 2.1 出域请求字段（`dmz/app.py` `_ALLOWED_TASK_FIELDS`）

| 字段 | 类型 | 是否可含客户数据 | 说明 |
|---|---|---|---|
| `request_id` | str | 否 | 全局唯一，用于全链路追溯与重放检测 |
| `session_id` | str | 否 | 会话标识（非客户号） |
| `intent_hint` | enum | 否 | 意图类别码，如 `DISPUTE_PROCESS` |
| `sanitized_context` | str | **是（已脱敏）** | 唯一承载业务语义的字段；已过 PII 清洗，出域前二次扫描 |
| `approved_rule_context` | list | 否 | 仅规则 id / version / summary，不含规则全文 |
| `allowed_output` | list | 否 | 允许外网返回的字段名，用于回程白名单 |
| `expires_at` | iso8601 | 否 | TTL 截止时间 |
| `trace_id` | str | 否 | 链路追踪号 |
| `signature` | hex | 否 | HMAC-SHA256（PoC）／生产为 mTLS + JWS |

**任何白名单外字段 → HTTP 400 `FIELD_NOT_ALLOWED`，审计 `EGRESS_DENIED`。**

### 2.2 回程响应字段（`common/schema.py` `ALLOWED_OUTPUT_FIELDS`）

结构化建议、依据摘要、待确认事项、风险标记、动作码、Agent/模型版本指纹。**不含任何原文**；回内网后才由 `restore_for_display` 在满足三元匹配时回填真实值。

### 2.3 字段级脱敏策略

见 `docs/19-字段级脱敏策略表.md`（字段 → 规则 → 令牌前缀 → 是否允许出域 → 恢复条件）。
