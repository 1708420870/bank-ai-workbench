# 微光「牛马仕」定位说明（一页纸）

> 对应审计编号：**X5 / B2 / C4**
> 用途：对外口径统一，防止被误写为"大模型"或"本地推理服务"。

---

## 一句话

**牛马仕（Bull Hermes）是微光自研的智能体（Agent），不是大语言模型，也不是模型推理服务。**

---

## 它是什么 / 不是什么

| 维度 | 牛马仕（本项目实现：`inner/agent.py:NiumashiAgent`） | 大语言模型 / 推理服务 |
|---|---|---|
| 本质 | 任务理解 → 步骤规划 → 选择模型 → 编排工具 → 组织结果的**调度者** | 给定 prompt 生成 token 的**生成器** |
| 是否含参数权重 | **不含**（不训练、不微调、不持有权重） | 含（数十亿参数） |
| 能否独立产生自然语言 | 不能，必须调用模型端点 | 能 |
| 是否可私有化部署到客户内网 | **是**（这是它的核心卖点） | 视供应商而定 |
| 换模型是否要改它 | **不用**（换端点即换模型） | — |
| 在数据链路上的位置 | 内网可信域内，可接触未出域上下文 | 可能在内外网任意一侧，按端点审批 |

---

## 三层分工（本项目实际实现）

```
┌─────────────────────────────────────────────────────────┐
│ 牛马仕 Agent（inner/agent.py）                            │
│   职责：理解任务 → 规划步骤 → 选端点 → 编排 MCP 工具      │
│   不产出业务裁决；不直接给客户回话；不碰客户库             │
└───────────────┬─────────────────────────────────────────┘
                │ 只调用"已登记 + 已审批"的端点
┌───────────────▼─────────────────────────────────────────┐
│ 模型连接器（inner/agent.py:ModelConnector）               │
│   职责：按意图选端点（内网/外网）→ 调模型 → 降级处理       │
│   端点清单见 docs/17；未审批的外网端点会被强制降级        │
└───────────────┬─────────────────────────────────────────┘
                │
┌───────────────▼─────────────────────────────────────────┐
│ 模型端点：ep-internal-a（Qwen3.5-9B-AWQ 私有算力）        │
│           ep-partner-b（外网模型，仅接 L1 脱敏上下文）     │
└─────────────────────────────────────────────────────────┘
```

**代码证据**（可直接打开核对）：
- `inner/agent.py:14-18` 文件头注释：*"牛马仕是微光工作室自研、唯一可私有化部署到客户内网的智能体产品……分层的目的：换模型不需要改 Agent，换 Agent 不需要改网络。"*
- `inner/agent.py:52-70`：`NiumashiAgent` 只做 `plan()`（任务规划），不产生文本
- `inner/agent.py:26-49`：`Endpoint` 与 `ENDPOINTS` 是独立登记表，与 Agent 解耦

## 三条对外表述纪律

1. **不得说**"牛马仕是一个大模型" → **应说**"牛马仕是自研 Agent，可接入多个模型端点"。
2. **不得说**"牛马仕在内网做推理" → **应说**"牛马仕运行在内网，调用内网或经批准的外网模型端点"。
3. **不得说**"模型给出的结论就是处理结果" → **应说**"模型只给建议，最终裁决由内网规则引擎和授权人员完成"（证据：`inner/rules.py:evaluate()` 在模型之后独立运行，`inner/service.py` 中 `ADJUDICATED` 状态由规则产出）。

---

## 为什么这个定位必须说清楚（验收影响）

| 如果定位错了 | 后果 |
|---|---|
| 牛马仕被当成"模型" | 会被追问"模型版本/参数量/训练数据"——答不上来，且直接违反 B2 |
| 牛马仕被当成"本地推理服务" | 会被认为"外网模型能力缺失"，A1「外网模型只做建议」被判不适用 |
| Agent 与模型合并描述 | 无法证明"换模型不改 Agent"，B3「端点独立配置」失去证据 |

---

## 复验方式

| 结论 | 复验命令/位置 |
|---|---|
| Agent 与模型分离 | `grep -n "class NiumashiAgent\|class ModelConnector" inner/agent.py` → 两个独立类 |
| 端点独立登记 | `python tools/check_endpoints.py` → 文档与代码一致 |
| Agent 无模型权重 | 仓库无 `.bin/.safetensors/.gguf` 权重文件：`find . -name "*.safetensors" -o -name "*.gguf"` 为空 |
| 模型不裁决 | `grep -n "def evaluate" inner/rules.py`；审计事件 `ADJUDICATED` 由 service 产生 |
