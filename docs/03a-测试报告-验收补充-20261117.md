## 五、与安全要求的对应

| 要求 | 验证证据 |
|---|---|
| ① 网络隔离 | 三区独立进程+端口，dmz 仅回环；pytest 网络隔离用例 |
| ② 数据不出域 | 边界测试第 4 项（卡号/手机号内网侧脱敏）；映射表仅内网 |
| ③ Agent 不做最终裁决 | 反馈答复经 DMZ 规则裁决，否决即 451 且转人工（第 10 项） |
| ④ 最小权限 | 接口白名单收敛（`09-接口说明.md` 68 端点），禁任意 SQL |
| ⑤ 全程可追溯 | 审计用例 6 项；每次调用可追到人/请求/规则/模型/结果 |
