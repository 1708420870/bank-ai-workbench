# 客户反馈小程序：正式上线路径与前置条件清单

版本 v1.0　日期 2026-11-18　对应代码：`miniprogram/`（当前状态：开发版可跑）

## 一、结论先行

小程序能否上线，不由代码质量决定，而由三件行政与技术前置事项决定，**缺一不可**：

1. **主体资质**：金融类目需《金融许可证》或总行授权文件，且小程序主体须完成微信认证；
2. **双重备案**：小程序备案（管局审核）+ 服务端域名的 ICP 备案，域名对外必须是 HTTPS；
3. **技术生产化**：真实身份换取、域名白名单开启、隐私协议、调试开关关闭。

当前状态：代码在开发版可完整跑通（提单 / 查单 / 会话 / 评价全链路）；上述三项**均未具备**。
本文的用途是把这条链路拆到可执行的颗粒度，并标清哪一步必须由主体方完成。

### 阶段 1：资质与类目（主体方操作，最容易卡住的一步）

- 类目建议：**金融业 → 银行**（次选「金融信息查询」，取决于实际功能边界）。
- 需上传《金融许可证》扫描件；分行/子公司名义申请时，另需总行授权文件。
- 审核会核对「类目与实际功能是否一致」。本小程序是**客服反馈收集**，不含理财销售、
  不含账户查询、不含转账，申报时应在业务说明里写清这三点边界，避免被要求补金融资质。
- 若主体确无金融牌照（如第三方集成商），只能由银行主体申请，或改为 H5 挂在行内公众号内，
  这条路径不需要小程序类目资质——**这是当前最现实的备选**。

### 阶段 2：备案（主体方操作）

| 备案类型 | 在哪办 | 常见耗时 | 前置材料 |
|---|---|---|---|
| 小程序备案 | 微信公众平台 → 设置 → 基本设置 → 小程序备案 | 1–20 个工作日 | 主体证件、负责人身份证、服务内容说明、承诺书 |
| 域名 ICP 备案 | 域名注册商 / 接入商 | 新办 7–20 个工作日 | 若复用行内已备案域名加子域，通常只需在接入商处加解析，无需重新备案 |

**未完成小程序备案不能提交审核**，这是硬门槛。

### 阶段 4：提审与发布（主体方操作）

- 提交材料：功能页面截图、业务说明、测试账号（本系统无需登录，说明「客户免登录使用」即可）。
- 金融类常见驳回原因：类目与功能不符、缺少金融资质、隐私指引未填、测试路径不可达
  （审核员在公网访问不到你的 HTTPS 域名时会直接驳回——域名必须公网可达）。
- 审核通过后发布；建议先灰度小流量。

## 六、上线前自检

```bash
node miniprogram/tools/preflight.js
```

检查项：网关是否 HTTPS、`ENV` 是否已切 `public`、`urlCheck` 是否已开启、是否残留调试
覆盖开关与 `console.log`、AppID 是否明显为测试号。任一项不通过即退出码 1，可用于发包前
的手工门禁。当前代码尚处开发版，自检预期为**不通过**——这是正常状态，见输出里的逐条说明。

## 七、风险与备选路径

| 风险 | 影响 | 备选 |
|---|---|---|
| 主体无金融资质 | 类目选不上，审核必挂 | 改为行内公众号内嵌 H5（无需小程序类目资质） |
| 域名备案周期长 | 拖住整个上线 | 复用行内已备案域名加子域 |
| 审核要求补资质 | 反复驳回 | 提前把业务边界写清（不含理财销售/账户查询/转账） |
| AppID 非本单位 | 无法上线 | 以本单位主体重新注册 |

**其中最需要先落定的是两件**：金融类目资质，以及备案域名。这两件不定，其余技术工作都
无法收敛到可提审状态。
